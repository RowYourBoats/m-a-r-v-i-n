title: On Real-Time Form
date: "2024-04-20"

excerpt: Thinking about how real-time engines change the relationship between designer and artifact.
---

Real-time engines change the relationship between designer and artifact. The thing you make is no longer fixed — it breathes, it responds, it drifts. This changes what it means to finish something.

When I started working with game engines for non-game projects, the hardest shift wasn't technical. It was accepting that the output would never look exactly the same twice. A poster is a poster. A real-time piece is a system that produces moments.

This has implications for how we think about craft. Precision doesn't disappear — it moves. You're no longer placing pixels; you're tuning ranges, writing rules, setting boundaries for behavior. The craft is in the constraints.
