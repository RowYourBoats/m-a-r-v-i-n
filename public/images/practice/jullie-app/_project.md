description: >
  Your career is stored as a pile of short text records, each one turned into a list of numbers (an embedding) that
  captures its meaning. A job description is turned into the same kind of numbers, plus a few other lenses. "Matching"
  is measuring which career records sit closest to the job description in that number-space -- then re-ranking with some
  non-vector signals on top. The career corpus never changes when you run a new job; only the question changes. Same
  subject, different viewer, different view.
